The instrumentFrom signal to forceDated test results

Two signals.
One stored record

An Arduino Nano reads the load-cell and pressure channels through two ADS1115 converters and writes interleaved measurements to microSD. The acquisition code schedules a nominal 320 sample pairs per second. Each converter is configured for 860 samples per second (SPS); that conversion setting is not the stored pair rate.

The stored values are the latest available channel readings, not a guarantee of perfectly simultaneous force and pressure samples. The analysis reconstructs time from an assumed sampling rate rather than individual sample timestamps. That time axis is useful for analysis but is not independent verification of the acquisition timing.

From calibration

Calibrate against a known load

The calibration tool averages readings under known cumulative loads and fits a straight line, reporting slope, offset and R². The reference-load axis in the example below is in kg, not newtons. A close fit describes that calibration dataset; it does not establish complete measurement uncertainty or prove that one fit applies to every test.

Calibration implementation

Preserve the signal
behind the summary

  1. Convert the units

    Calibration turns measured values into force and pressure. An exported field called raw_force_N is already converted to newtons; it is not a raw ADC count.

  2. Set the baseline

    The horizontal-baseline option subtracts a constant offset. Gauge pressure uses an initial baseline. This is not dynamic thermal-drift compensation.

  3. Filter offline

    A forward/backward Butterworth low-pass filter produces a zero-phase offline result, not a causal real-time filter. Unfiltered and filtered force and pressure remain available for comparison.

  4. Report the analysis window

    An algorithm selects an event window from processed force. Peak thrust, duration, force-integrated impulse and mean thrust depend on that window and the reported analysis settings. Specific impulse additionally needs propellant mass; it is not inferred from the force trace alone.
