Avionics 소스 살펴보기

소스 버전 7cfb5be0
2026년 9월 17일 확인

PSI의 현재 비행 컴퓨터는 Arduino Portenta H7의 두 코어에 작업을 나눕니다. M7은 센서 처리와 비행 판단을, M4는 SD 기록과 XBee 원격 측정 경로를 담당합니다. 지상으로 전송하는 데이터와 함께 기체 내부에도 기록을 남기는 구조입니다.

M7
비행 루프 · 설정 주기 100 Hz

센서 수집, 수직 상태 추정, 비행 상태와 회수 판단을 담당합니다.

M4
기록과 원격 측정 · 전송 설정 주기 25 Hz

간추린 데이터를 XBee로 전송하며 별도 SD 기록 스레드로 저장합니다.

수직 운동 상태 추정

무향 칼만 필터(UKF)는 IMU의 전역 Z축 가속도와 기압 고도를 결합하며, 새로운 기압 샘플이 들어올 때 약 50 Hz로 갱신합니다. GNSS는 위치 기록과 회수에 활용하며, 이 수직 상태 UKF나 비행 상태 판단 경로의 입력은 아닙니다.

위 주기는 소프트웨어 설정 기준이며 전체 시스템의 실측 성능을 보장하는 수치가 아닙니다.

비행 컴퓨터 안내 읽기

통합 지상국

현재 Python 인터페이스는 3D 자세, 위치 이력과 비행 측정값을 하나의 대시보드에 모읍니다. 가속도, 각속도, 고도, 수직 속도, 예측 최고 고도 그래프를 제공하며 기본 화면에는 가속도와 고도 그래프가 표시됩니다. 위치 이력은 격자 또는 오프라인 지도와 함께 살펴볼 수 있습니다.

비행 통계, 센서 데이터 갱신 상태, 텔레메트리와 시스템 로그를 기록 재생 기능과 함께 제공합니다. 로그를 열고 일시 정지하거나 위치를 이동하고 1–50배속으로 재생하며 시험 후 데이터를 검토합니다. 센서 상태 표시는 수신 데이터의 최신성을 나타내며 GNSS 위치 확정이나 비행 준비 상태를 보장하지 않습니다.

TMS 저장소 살펴보기

추력 측정 시스템(TMS)은 계측 장치를 사용한 지상 시험을 교정, 기록, 분석으로 연결합니다. 센서 신호가 검토 가능한 측정값이 되는 과정을 추적할 수 있도록 합니다.

데이터 수집과 저장

Arduino Nano가 두 ADS1115 채널을 통해 로드셀과 압력 신호를 읽고 SD 카드에 측정값을 저장합니다. 수집 코드는 초당 320개 샘플로 설정되어 있으며, 이는 ADC 자체의 변환 속도 설정과 구분됩니다.

교정과 해석

Python 도구로 교정, 필터링, 추력과 충격량 분석을 수행합니다. 공개 시험 아카이브에는 처리된 데이터와 함께 그래프, 실험 노트, 계측 이상과 한계가 남아 있습니다.

항공기 프로젝트

로켓을 넘어,
항공기로.

항공기팀은 경진대회 활동을 위해 쿼드로터와 VTOL 비행체를 설계하고 제작합니다.

연구 아카이브에는 보텍스 생성기가 비행 안정성에 주는 영향과 메조구조가 소형 비행체의 거동에 주는 영향을 다룬 연구도 있습니다. 과거 연구와 현재 활동은 비행을 탐구하는 서로 다른 방식입니다.

현재 정밀 착륙 연구는 기존 제어기와 PPO 기반 잔차 보정을 결합합니다. 시뮬레이션으로 가능성을 검토하는 단계이며 실제 비행 검증은 앞으로의 과제입니다.
