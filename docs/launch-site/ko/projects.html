로켓 프로젝트

PSLV

POSTECH Science Launch Vehicle

PSLV 프로젝트는 비행체 제작, 에비오닉스 통합, 발사와 회수를 연결합니다. 공개 기록에는 2024년 11월 1세대 발사, 2025년 8월 에비오닉스 비행, 같은 해 12월 PSLV-II가 담겨 있습니다.

Avionics 저장소 살펴보기

로켓에는 프로세서뿐 아니라 센서에서 판단과 원격 측정까지 이어지는 일관된 데이터 흐름이 필요합니다. PSI의 공개 비행 소프트웨어는 Arduino Portenta H7에서 실행되며 RTOS로 작업을 나눕니다.

센서와 상태 추정

코드는 GNSS, IMU, BMP3XX 기압 센서와 연결됩니다. 현재 필터 구현은 수직 가속도와 기압 고도로 운동 상태를 추정합니다. GNSS는 위치 정보를 제공하며, 동일한 상태 추정 필터에 통합된 입력으로 해석하지 않습니다.

원격 측정과 지상국 소프트웨어

XBee로 측정값을 Python 지상국에 전달합니다. 실제 인터페이스는 3D 자세 모델과 비행 상태, GNSS 기반 경로, 3축 가속도 그래프를 보여 줍니다. 시간 정보가 있는 로그로 고도, 속도, 압력, 예측 최고 고도를 나중에 다시 분석할 수 있습니다.

공개 소프트웨어에서 확인할 수 있는 기능을 설명합니다. 인증이나 신뢰성, 모든 기능의 특정 비행 탑재를 의미하지 않습니다.

TMS 저장소 살펴보기

추력 측정 시스템(TMS)은 계측 장치를 사용한 지상 시험을 교정, 기록, 분석으로 연결합니다. 센서 신호가 검토 가능한 측정값이 되는 과정을 추적할 수 있도록 합니다.

데이터 수집과 저장

Arduino Nano가 두 ADS1115 채널을 통해 로드셀과 압력 신호를 읽고 SD 카드에 측정값을 저장합니다. 수집 코드는 초당 320개 샘플로 설정되어 있으며, 이는 ADC 자체의 변환 속도 설정과 구분됩니다.

교정과 해석

Python 도구로 교정, 필터링, 추력과 충격량 분석을 수행합니다. 공개 시험 아카이브에는 처리된 데이터와 함께 그래프, 실험 노트, 계측 이상과 한계가 남아 있습니다.

항공기 프로젝트

로켓을 넘어,
항공기로.

항공기팀은 경진대회 활동을 위해 쿼드로터와 VTOL 비행체를 설계하고 제작합니다.

연구 아카이브에는 보텍스 생성기가 비행 안정성에 주는 영향과 메조구조가 소형 비행체의 거동에 주는 영향을 다룬 연구도 있습니다. 과거 연구와 현재 활동은 비행을 탐구하는 서로 다른 방식입니다.

2026년 4월에는 강화학습 기반 착륙 연구 주제가 선정되었습니다. 이는 연구 목표이며 자율 착륙을 실증했다는 주장은 아닙니다.
